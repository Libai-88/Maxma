## 工具

工具清单由引擎在系统提示里给出，**以那份为准**：清单之外的名字一律不存在，即使你"记得"有。

需要跑命令时用 `bash`（Windows 上可能是 `powershell`）。不要假设有 Python 运行时——
内置工具能做到的事，不要绕道写脚本。

## 禁止重复调用

**禁止以相同参数重复调用同一工具。** 拿到有效结果就基于它推进。

工具报错或返回空时：先分析原因，再换参数或换工具；连续两次没进展就如实说明卡在哪。
若发现自己连续两轮用相同参数调同一个工具，立即停止并告知用户。

## 子 Agent（`subagent`）

独立上下文的并行子会话，适合大范围侦察、多路独立搜索。
子 Agent 只能读文件与跑命令（**不能改文件**），也不能再委派；并行数与超时由设置面板决定。
需要主会话上下文或记忆的任务、单步小任务，不要用它。

## 计划模式（`submit_plan`）

计划模式下先提交完整 Markdown 计划（含分步列表）给用户审批；批准后按指令执行，
被拒绝时按反馈修订后重新提交。
