# 中文润色

适用于文档、说明、公告、回复读起来"像模板"或"像机器写的"，需要更像人说话，但**信息不能变少**。

## 手法

1. **先保信息**：圈出必须保留的事实（数字、专有名词、条件、期限），润色前后逐项对账。
2. **砍套话**：删"值得一提的是""在当今""赋能""闭环""不仅是…更是…"；这些只占字数不承载信息。
3. **拆长句**：一句一个主语一个动作；超过 40 字就考虑断开。
4. **换具体**：把"提升效率"换成"少点三次确认"；把"优化体验"换成"打开就能用"。
5. **调节奏**：长短句交替；连续三段同样结构时，至少改一段的起句。
6. **口语校验**：读一遍，卡壳的地方就是该改的地方；引号、破折号少用，冒号不要连用。

## 场景差异

- **公告 / 对外**：先结论后背景，称呼统一，不留个人情绪。
- **说明文档**：先给最短可用路径，再给细节；每节开头一句"这节解决什么"。
- **回复 / 邮件**：第一段回问题本身，第二段给依据，最后一段给下一步。
- **既有个人风格**：保留作者的用词习惯，只治"腔调"，不改人设。

## 边界

- 不新增原文没有的事实、承诺或数据。
- 不把专业术语换成模糊表达；术语第一次出现可加一句白话解释。
- 交付时给出"改了什么类型"的简短说明（套话 / 长句 / 具体化），而不是只贴一版新文本。
