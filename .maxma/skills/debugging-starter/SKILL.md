# 调试入门

适用于报错、功能失效、结果异常或程序运行缓慢的场景。

## 工作方式

1. 记录实际操作、预期结果、实际结果和完整错误信息。
2. 用 `grep`、`find`、`read` 查找日志、配置和相关代码，先定位再修改。
3. 用最小范围实验验证一个根因假设，不同时改动多个无关模块。
4. 用 `edit` 完成修复，运行直接相关测试或命令，并复核原始症状。
5. 交付时说明根因、修复文件和验证结果。

## 安全边界

- 不删除日志、数据或配置来掩盖问题。
- 不把密钥、令牌或个人数据复制到调试输出。
- 修改配置、依赖或运行环境前说明影响范围。
