# 文档质量

适用于 Markdown、文本、CSV、DOCX、XLSX、PDF 和需要交给他人继续使用的文件。

## 工作方式

1. 明确读者、用途、目标格式、输出路径、语言和覆盖策略；默认在新路径生成结果并保留原稿。
2. 先检查输入是否完整，再按文件格式读取；不要把无法解析的二进制文件当作纯文本臆测。
3. 生成后核对标题层级、段落、列表、表格、链接、编码、数字、日期、单位和引用；表格额外核对列名、行数、空值和关键合计。
4. 有渲染能力时打开或渲染最终文件，检查分页、截断、乱码、图片和链接；没有工具时明确未完成视觉核验。
5. 交付只提供最终文件路径和必要的使用说明，不把临时文件、日志或中间稿混入交付目录。

## 质量边界

- 不覆盖原稿，不删除输入数据，不改变字段含义或数值精度。
- 不发送、上传、共享或发布文件，除非用户明确要求。
- 发现密钥、个人信息或内部地址时，先停止外发并提示用户处理。
