# 表格入门

适用于 CSV、TSV、JSON 或可通过当前本地工具读取的表格数据；XLSX 需要本机已有解析工具或用户主动配置 MCP。

## 工作方式

1. 确认输入文件、目标格式、字段含义、筛选规则、排序规则和输出位置。
2. 用 `read` 读取小样本或表头，用 `grep` 查找异常值；大文件先抽样，不直接全量覆盖。
3. 处理前保留原文件，明确日期、数字、空值、重复行和编码规则。
4. 用 `write_office_file` 生成 XLSX/CSV/TSV 新结果，核对行数、列名、关键合计和文件可读性。
5. 交付结果文件路径，并说明采用的字段与计算规则。

## 安全边界
- 不为 DOCX、XLSX、PDF 或其他二进制格式臆造解析结果；缺少本地工具时明确说明限制。
- 不擅自删除原始行或改变金额、日期和身份字段的含义。
- 不把个人、财务或客户数据发送到外部服务。
- 不把估算值当作原始数据或精确结果。
