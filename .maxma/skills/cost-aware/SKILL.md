# 成本控制

适用于长文档、长会话、批量文件、网页资料和需要多轮工具调用的任务。

## 工作方式

1. 先读取目录、标题、元数据或小样本，确认真正相关的范围，再读取正文或全量数据。
2. 对长内容分层处理：先提取结构和关键字段，再针对缺口读取原文；不要为了省 token 删除影响结论的限定条件、数字、错误信息或来源。
3. 合并重复的搜索、读取和验证动作；一次工具调用能安全完成的工作不要拆成无意义的多轮。
4. 输出优先给结论、证据和可执行动作；用户要求完整内容时保留完整内容，不用摘要替代交付物。
5. 只有在用户允许且不改变结果语义时才压缩、改写或去重。

## 质量边界

- 不使用代理、远程摘要服务或额外 MCP 来默认降低成本。
- 不隐藏失败、警告、来源、单位、时间范围或不确定性。
- 不把截断后的样本当作全量结果；明确抽样、过滤和估算规则。
