# MCP 入门

适用于用户想连接外部工具、服务或数据源的场景。

## 工作方式

1. 先检查 Maxma 原生工具是否已经覆盖当前任务；默认覆盖文件与本地代码操作，浏览器、网页搜索和 GitHub 等外部能力需要另外配置 MCP。
2. 确认 MCP 的用途、传输方式、所需程序、凭据、网络访问和数据范围。
3. 只使用真实兼容的 `stdio` 或 `streamable_http` 配置；其他 transport 先说明当前引擎不支持。
4. 默认关闭新服务，先做最小连接测试，再限制允许的工具和目录。
5. 交付时明确哪些能力需要用户自行安装程序、提供凭据或承担网络服务费用。

远程服务只有在用户提供凭据后才添加认证头；凭据为空时不要保存空的 `Authorization` 或 API key 字段。

## 安全边界

- 不把需要 API key、订阅或付费额度的服务描述为免费。
- 不代替用户猜测凭据、开放公网端点或扩大文件访问范围。
- MCP 连接失败时优先回退到 Maxma 原生工具，不阻塞本地工作流。
