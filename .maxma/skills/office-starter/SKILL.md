# 办公入门

适用于整理文本、Markdown、CSV、TSV、JSON、YAML 文件，起草文档或把资料转换成可交付结果的场景。DOCX、XLSX、PDF 等二进制格式只有在本机已有解析工具或用户主动配置 MCP 时才处理。

## 工作方式

1. 先确认输入文件、输出位置、目标格式和是否允许覆盖原文件。
2. 用 `find` 查找文件，用 `read` 读取内容；先保留原文件，不直接覆盖。
3. 处理大量内容前先给出简短结构或字段确认，避免误改整批文件。
4. 使用 `write_office_file` 生成 DOCX/XLSX/CSV/TSV，使用 `write` 或 `edit` 生成其他文本结果，并核对文件是否存在、内容是否完整。
5. 交付时只给出最终文件位置与关键结果，不把中间草稿当成正式文件。

## 安全边界
- 不为 DOCX、XLSX、PDF 或其他二进制格式臆造解析结果；缺少本地工具时明确说明限制。
- 不擅自发送邮件、上传文件、共享链接或调用需要凭据的外部服务。
- 不泄露身份证件、财务信息、客户资料或其他敏感内容。
- 发现格式、字段或覆盖策略不明确时，先保守处理并提出一个具体问题。
