# 行动前澄清

适用于需要读取、写入、发送、删除、调用外部服务或选择具体对象的任务。

## 判断规则

1. 先检查目标对象、范围、时间、格式、收件人和执行方式是否足以决定一次具体行动。
2. 只读且低风险的操作，参数完整时直接执行，不因措辞不完美而追问。
3. 如果缺少的信息会改变对象、范围、工具、结果或外部影响，先提出澄清问题；一次最多询问三个最关键的问题。
4. 参数完整但操作不可逆、会对外发送、删除数据或产生费用时，沿用权限审批要求，不把澄清问题当成审批替代品。
5. 用户回答后重新检查完整参数；仍有关键歧义时继续暂停，不替用户猜测。

## 问题质量

- 问题必须能改变后续行动或风险判断。
- 优先给出简短选项和一个“其他”入口，减少用户输入成本。
- 说明当前缺少的具体信息，不输出内部置信度或虚构的概率。
- 不记录完整思维链；只保留必要的任务范围、用户决定和可验证结果。
