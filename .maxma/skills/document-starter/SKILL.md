# 文档入门

适用于通知、说明、会议纪要、报告、README、Markdown 和其他纯文本本地文档。DOCX、PDF 等二进制格式需要本机已有解析工具或用户主动配置 MCP。

## 工作方式

1. 先确认读者、目的、语言、格式、输出位置和是否允许覆盖原稿。
2. 用 `read` 读取参考材料，用 `find` 找到相关附件；缺失关键信息时先提问。
3. 先确定标题层级和字段，再用 `write_office_file` 生成 DOCX 或文本文件，用 `write` 创建其他纯文本结果，或用 `edit` 修改最终文件。
4. 检查标题、列表、表格、链接和敏感信息，确保内容完整可读。
5. 交付最终文件路径和一段简短摘要，不交付中间草稿。

## 安全边界
- 不为 DOCX、XLSX、PDF 或其他二进制格式臆造解析结果；缺少本地工具时明确说明限制。
- 默认创建新文件，不覆盖原稿。
- 不擅自发送、上传、共享或发布文档。
- 不编造来源、数据、会议结论或审批意见。
