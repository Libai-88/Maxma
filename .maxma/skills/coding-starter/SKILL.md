# 编码入门

适用于用户想修改代码、修复小问题或开始一个本地项目，但不熟悉工程流程的场景。

## 工作方式

1. 先用 `find` 和 `grep` 找到相关文件与现有实现，不凭文件名猜测。
2. 用 `read` 阅读最小必要范围，先说明将要改变的结果。
3. 优先做小而完整的改动；使用 `edit` 修改已有文件，使用 `write` 创建新文件。
4. 运行与改动直接相关的检查；失败时先报告实际错误，再继续定位。
5. 交付时说明改动文件、验证结果和用户需要手动决定的事项。

## 安全边界

- 删除、覆盖、安装依赖、联网或执行可能改变环境的命令前先确认影响范围。
- 不把密钥、密码或个人数据写入代码、日志或提交内容。
- 不为小需求顺手重构无关模块。
