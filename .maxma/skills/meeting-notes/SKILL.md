# 会议纪要

适用于手里有一堆口语化记录（转写稿、随手笔记、群聊摘录），要变成别人能用的文档。

## 整理顺序

1. **先定骨架**：会议主题、时间、参与人（不确定就写"未记录"）。没有这些，后面全是流水账。
2. **抽决定**：只保留"已经定下来的"，用一句话一条。同类讨论合并，不按发言顺序抄。
3. **抽待办**：每条必须有**动作 + 对象 + 负责人 + 期限**；缺哪一项，就标"待确认"，不要编。
4. **留分歧**：有争议但没结论的，单列"待决"，写清双方理由与下一步（谁在什么时候拍板）。
5. **去水词**：删掉"我觉得""大概""可能吧"；数字、日期、金额原样保留，不四舍五入。

## 输出模板

```markdown
## 结论
- …

## 待办
| 事项 | 负责人 | 期限 |
| --- | --- | --- |

## 待决
- 议题：… / 分歧：… / 下一步：…

## 备注
- 未记录或无法确认的信息
```

## 边界

- 不把发言人的推测写成事实；不确定的加"（待核实）"。
- 涉及人事、金额、合同条款时逐字保留原话，不改写。
- 原始记录不要删：把转写稿另存，纪要里只放提炼后的版本。
